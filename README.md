编队外观与选人界面修订测试版，保留玩家创建、自由编队与关卡选择。非官方回合制实验，支持离线游玩。

> 验证记录（2026-10-11）：最终发布冻结聚合28/28条有效命令通过，234个运行/素材文件前后零漂移；真实云Chrome在已记录的核心范围通过。用户已要求发布GitHub预发布版；提交、标签及附件是否上传成功，以远端回执为准。具体未验项见下文。

上一公开版本：[test.7 Release](https://github.com/Whirock/Wuwa-battlesystem-testversion/releases/tag/v3.0.0-test.7)。此链接仅提供 test.7。本轮 test.8 已获用户发布指令，目标仓库为 `Whirock/Wuwa-battlesystem-testversion`，预发布标签为 `v3.0.0-test.8`；此文档不提前证明远端标签、Release 或附件已经创建。

## 开始

取得游玩版 ZIP 后，完整解压并打开 `index.html`。Windows 也可双击「启动遭遇演算.cmd」。运行无需安装依赖或联网，请保留完整目录。原生 Windows 双击启动仍需单独验收。

## 本轮修订范围

- 编队按身体基准统一人物尺度，重点修正琳奈偏大；保持原图比例并检查完整可见性。
- 定位详情提供即时换肤预览；快速选人的临时修改随“完成选择”进入编队草稿，取消则丢弃。
- 快速选人将双模态控件放在“定位详情”下方；漂泊者在相同位置切换男/女，并保留当前衣装。
- 工作台当前换肤同步当前编队及打开草稿；五个已保存预设保留各自外观快照，显式载入预设会恢复其保存外观。
- 先盘点保存鸣潮原图标，再查资源站补缺，最后处理自绘缺项；保存、接入及分发状态分别核验。

已接入14张原作图标：6元素、1治疗职责、6基础数值、1真实吸收护盾。其余15类项目职责继续使用SVG；SP/SPD等不强配。原字节、语义和回退范围见 `assets/ui-icons/SOURCES.json` 与 `ICON_USAGE.md`。详细使用方式见 [test.8修订说明](docs/test8-changes.txt)。

## 新版入口

- 玩家创建：两套着装体型、各五个语义姿态；七类跨性别发型、四种瞳型，以及肤色、发色、瞳色调色。
- 属性与技能：十个数值模板、1–90 级成长与八属性编辑；十六类结构化附加机制。推荐区间与“破限”分开校验。
- 编队：角色卡片、属性与等级、模态选择、定位详情、快速头像选择，以及五个队伍预设。
- 关卡：独立选择七个既有关卡和难度，再以当前编队出战。
- 素材工作台：保留图片、背景、声音和项目导入导出功能。

保留九个角色配置、六十一张技能卡、一百九十一张既有运行PNG和原创建组件，本轮新增14张本地UI图标。漂泊者属性配置属于同一身份，一队最多选一个。战斗临时形态的卡片预览不会替代进入该形态的技能与资源条件。

创建器的推荐数值属于平衡候选。“破限”允许超过推荐区间，仍拒绝无效数据及不受支持的触发结构。技能描述用于说明，实际效果由所选机制决定。BP 按通用战斗规则使用，不在创建器中另设费用。详见 [玩家创建与编队说明](docs/test7-player-creation.txt)。

## 保存与升级

本轮只修改 UI 与外观，沿用 test.7 的项目格式 `resonant-project-test7`、version 7 和 `resonant-encounter-lab-test7` 浏览器存储（数据库版本 1）。显示为 test.8 不表示改用新空库；test.7项目兼容和五预设独立恢复已通过自动化；真实浏览器另验证一个预设栏与当前队伍保存刷新。更早旧规则项目继续按既有提示迁移支持的素材和设置，不能把 test.7 项目误当旧规则战局重开。更新或移动离线文件夹前，建议导出项目备份。

若浏览器存储不可用或额度不足，以界面实际保存回执为准；当前会话中的编辑应及时导出备份，不能把会话保留理解为已永久保存。
