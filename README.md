# 鸣潮回合制 · test.7

玩家创建、自由编队与关卡选择测试版。非官方回合制实验，支持离线游玩。

版本：`v3.0.0-test.7`，程序版本：`0.5.0-creation-candidate`。

> 验证定稿（2026-10-11）：本轮最终自动化聚合与真实云 Chrome 验证已完成。数值仍是平衡候选，用户美术终审尚未完成；ZIP 文件完整性及远端发布以实际 SHA 和 Release 回执为准。

下载与版本记录：[test.7 Release](https://github.com/Whirock/Wuwa-battlesystem-testversion/releases/tag/v3.0.0-test.7)。本说明不代替该页的实际附件、标签与提交记录。

## 开始

取得游玩版 ZIP 后，完整解压并打开 `index.html`。Windows 也可双击「启动遭遇演算.cmd」。运行无需安装依赖或联网，请保留完整目录。原生 Windows 双击启动仍需单独验收。

## 新版入口

- 玩家创建：两套着装体型、各五个语义姿态；七类跨性别发型、四种瞳型，以及肤色、发色、瞳色调色。
- 属性与技能：十个数值模板、1–90 级成长与八属性编辑；十六类结构化附加机制。推荐区间与“破限”分开校验。
- 编队：角色卡片、属性与等级、模态选择、定位详情、快速头像选择，以及五个队伍预设。
- 关卡：独立选择七个既有关卡和难度，再以当前编队出战。
- 素材工作台：保留图片、背景、声音和项目导入导出功能。

既有九个角色配置、六十一张技能卡和一百九十一张运行 PNG 保留。漂泊者属性配置属于同一身份，一队最多选一个。战斗临时形态的卡片预览不会替代进入该形态的技能与资源条件。

创建器的推荐数值属于平衡候选。“破限”允许超过推荐区间，仍拒绝无效数据及不受支持的触发结构。技能描述用于说明，实际效果由所选机制决定。BP 按通用战斗规则使用，不在创建器中另设费用。详见 [玩家创建与编队说明](docs/test7-player-creation.txt)。

## 保存与升级

本版使用独立存储。旧版项目可迁移支持的素材和设置，旧规则战局需要重新开始；同版项目按当前校验规则恢复。更新或移动离线文件夹前，建议导出项目备份。

若浏览器存储不可用或额度不足，以界面实际保存回执为准；当前会话中的编辑应及时导出备份，不能把会话保留理解为已永久保存。

## 验证与复现

最终聚合 20/20 条命令通过，用时 72.774 秒，18 个运行文件在执行前后无漂移。覆盖既有角色 189 组新旧对照、5,126 次成对行动；全量创建属性区间；结构化技能、输入、编队、存储失败及旧规则回归。不同检查存在重叠，不合并成“独立测试总数”。

真实云 Chrome 已验证创建→入队→选关→战斗→保存刷新、五个预设跨刷新、桌面/窄屏布局及 r004 组件图集。40 个实际渲染样本经目视检查，另有 280 个实际组合渲染零失败，不能称为 280 组人工逐像素验收。原生 Windows 双击、实际音频、最终数值平衡及用户美术终审仍未认证。详见 [测试报告](测试报告.txt) 和 [验证边界](docs/test7-validation.txt)；完整包或仓库另含 [自动化结果](tests/v07/results-final.json) 与 [真实浏览器记录](tests/v07/browser/coverage.json)。

完整源码测试包保留可复现测试与依赖锁文件；游玩包不含整套测试。两者应在全新解压目录、安装测试依赖或运行测试之前执行：

    python tools/verify_publication.py

Release ZIP 的默认模式严格核验完整文件树、SHA-256 与随包素材描述。Git 克隆保留历史 archive 和旧测试目录，应改用：

    python tools/verify_publication.py --repository

仓库模式仍拒绝本版清单文件缺失、改动、不安全路径和活动 assets 目录多余文件；另报告未纳入本次验证的保留历史文件清单与数量，不把它们宣称为已验证。两种模式都不认证游戏性或美术质量。完整包或仓库再按 `tests/v07/README.md` 安装测试依赖并运行 `node tests/v07/run_all.cjs`。测试会产生新证据文件；重验原始交付完整性时应重新解压一份干净副本。
