## 比较与边界

前后对比在同一1366×768视口、默认队伍和普通遭遇下截取；旧版副本只使用独立QA存储，原test.4页面和程序未改写。显示身体基准在900×400绘图区由44px增至86px，约1.955倍；最终桌面大小随视口变化，大型头目单独等比适配。

平台的 Edit site 浮动按钮属于预览宿主，不在离线包。窄屏允许菜单内部滚动以保留所有技能。浏览器结果不代表Windows双击、音频实际播放、真人乐趣或最终平衡通过。

## 显示比例实现

一般人物以身体参考高度统一缩放，透明边距不会作为身高。头目保留原始 nominal bodyScale（无妄者3.5），最终绘制再施加左侧/高度安全范围；投射物存在时预留底部目标通道。该响应式适配仅改变绘制比例和位置，不改变战斗数值、命中选择或素材文件。
